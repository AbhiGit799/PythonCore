Let's understand Binary Search Tree (BST), DFS, and BFS in 
a simple way with examples. 
Since you're learning Binary Tree DSA for LeetCode, we'll build it step by step.

1. What is a Binary Search Tree (BST)?
***************************************
A Binary Search Tree is a special type of binary tree that follows a rule:

- Left child: contains a value smaller than the parent.
- Right child: contains a value greater than the parent.

For example, consider this tree:

Example of a Binary Search Tree

Let's check the rule:

- `3 < 8` → 3 goes to the left of 8.
- `10 > 8` → 10 goes to the right of 8.
- `1 < 3` → 1 goes to the left of 3.
- `6 > 3` → 6 goes to the right of 3.

That's a BST!

Important: Every node must follow the BST rule relative to all its ancestors, not just its immediate parent.

2. How is a BST different from DFS and BFS?
*******************************************
This is the most important distinction:

| BST                                               | DFS                                           | BFS                             |
| ------------------------------------------------- | --------------------------------------------- | ------------------------------- |
| A type of binary tree                             | A way to traverse a tree                      | A way to traverse a tree        |
| Follows smaller-left, greater-right rules         | Goes deep before backtracking                 | Visits level by level           |
| Helps with searching and maintaining ordered data | Useful for paths, depth, and subtree problems | Useful for level-based problems |

Think of it like this:

- BST = How the tree is organized.
- DFS and BFS = How you visit the nodes.

You can perform DFS or BFS on a BST, and you can also perform DFS or BFS on a normal binary tree.

3. DFS: Depth-First Search
******************************
DFS goes as deep as possible along one path before returning to explore another path.

Using our tree:

DFS example — Inorder traversal

## 1 -> ## 3 -> ## 6 -> ## 8 -> ## 10

Inorder: Left → Root → Right

DFS has three common depth-first traversal orders:

- Inorder: Left → Root → Right
- Preorder: Root → Left → Right
- Postorder: Left → Right → Root

Notice that inorder traversal of a BST gives the values in sorted order: `1, 3, 6, 8, 10`.

4. BFS: Breadth-First Search
*****************************
BFS visits all nodes at one level before moving to the next level.

BFS example — Level-order traversal

## 8

## 3  ## 10

## 1    ## 6

BFS order: 8 → 3 → 10 → 1 → 6

BFS typically uses a queue (First In, First Out).

DFS typically uses recursion or a stack.

5. How do we search for a value in a BST?
******************************************
Suppose we want to find `6`.

1. Start at `8`.
2. Since `6 < 8`, go left to `3`.
3. Since `6 > 3`, go right to `6`.
4. Found it!

Python example:
****************

def searchBST(root, val):
    if root is None or root.val == val:
        return root

    if val < root.val:
        return searchBST(root.left, val)

    return searchBST(root.right, val)



The BST property tells us which direction to take, so we don't need to visit every node.

Remember these three points for LeetCode:

- BST problems → focus on the smaller-left, greater-right rule.
- DFS problems → look for recursion, paths, depth, or subtree calculations.
- BFS problems → look for level order, nearest level, or maximum/minimum level values.

A problem can use more than one approach, so the question's requirements determine which technique is best.

4. Let's compare them in one enterprise scenario
****************************************************
Imagine you're building a banking application with customers, accounts, and services.

BFS — Find nearby connections

Find accounts connected to a suspicious account through the fewest account-to-account links.

DFS — Explore the whole connection chain

Follow linked accounts and their connections to explore a network. Real fraud detection needs additional rules and analysis; DFS alone does not determine fraud.

BST — Search ordered records

Find an account ID in an in-memory ordered collection or retrieve accounts within an ID range.

 5. What should you learn for enterprise development?
*********************************************************
Since you're learning Python and preparing for Data Engineering and software development interviews, I recommend this order:

| Priority | Topic | What to practice                                                  |
| -------- | ----- | ----------------------------------------------------------------- |
| 1        | DFS   | Recursion, tree depth, paths, traversing nested data              |
| 2        | BFS   | Queue, level-order traversal, shortest paths in unweighted graphs |

One practical point: in enterprise Python applications, you may use built-in dictionaries, sets, database indexes, 
and graph libraries instead of implementing a BST yourself. 
However, understanding these algorithms helps you choose and reason about the right data structure.

Remember: BFS and DFS describe ways to explore data. A BST describes how data is organized. They solve related but different problems.
