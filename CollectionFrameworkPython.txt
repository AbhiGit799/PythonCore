In Python, the Collection Framework usually refers to the different data structures used to store and manage multiple values. Unlike Java, Python does not have an official framework specifically called the Collections Framework. Instead, Python provides built-in collection types and a collections module.



Since you are learning Python and DSA, let's understand this from the basics.

1. Four main collection types in Python

1. List — list

Stores multiple values, allows duplicates, and is mutable (changeable)

numbers = [10, 20, 20, 30]
numbers.append(40)
print(numbers)
# [10, 20, 20, 30, 40]


2. Tuple — tuple

Stores multiple values, allows duplicates, but is immutable (cannot be changed after creation).

numbers = (10, 20, 30)
print(numbers[0])
# 10


3. Set — set

Stores unique values and automatically removes duplicates. It is unordered.

numbers = {10, 20, 20, 30}
print(numbers)
# {10, 20, 30}



4. Dictionary — dict

Stores data as key-value pairs.

student = {
    "name": "Rahul",
    "age": 22
}

print(student["name"])
# Rahul


2. What is Python's collections module?
Python also provides a built-in module named collections. It contains specialized data structures that are especially useful for DSA and coding interviews.


Data structure    Purpose                                             Common use
------------------------------------------------------------------------------------------------------------------
Counter           Counts occurrences of elements                      Frequency counting
defaultdict       Supplies a default value for missing keys           Grouping and counting
deque             Adds/removes elements efficiently at both ends      Queue and sliding window
OrderedDict       Maintains insertion order with ordering operations  Specialized dictionary operations
namedtuple        Creates tuple-like objects with named fields        Simple structured records
ChainMap          Combines multiple mappings into one view            Layered configurations



Let's understand the three most useful ones for DSA.

A. Counter — count frequencies

from collections import Counter

numbers = [1, 2, 2, 3, 3, 3]

frequency = Counter(numbers)

print(frequency)
# Counter({3: 3, 2: 2, 1: 1})


Here, Python counts how many times each number occurs.
- 1 occurs once.
- 2 occurs twice.
- 3 occurs three times.
Useful in problems such as finding duplicate elements, anagrams, and frequency comparisons.

B. defaultdict — automatic default values

from collections import defaultdict

frequency = defaultdict(int)

numbers = [1, 2, 2, 3]

for num in numbers:
    frequency[num] += 1

print(dict(frequency))
# {1: 1, 2: 2, 3: 1}


Normally, accessing a missing dictionary key can raise a KeyError. With defaultdict(int), a missing key starts at 0, because int() returns 0.


C. deque — efficient queue

from collections import deque

queue = deque()

queue.append(10)
queue.append(20)
queue.append(30)

print(queue.popleft())
# 10

print(queue)
# deque([20, 30])

deque supports efficient additions and removals at both ends. It is useful for BFS (Breadth-First Search), queues, and some sliding-window problems.


3. Python collections vs Java Collection Framework

Since the phrase Collection Framework is commonly used in Java, here is the comparison.

Concept	                       Java	                  Python

Dynamic array	               ArrayList	           list

Unique elements	               HashSet	               set

Key-value storage	           HashMap	               dict

Queue / double-ended queue	   Queue , Deque	       collections.deque

Frequency counting	           Usually a Map	       collections.Counter

Stack	                       Stack or Deque	         list


Important: Python's list is not exactly the same as Java's ArrayList, but both can store multiple elements and grow dynamically.
